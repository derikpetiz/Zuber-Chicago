Análise de Corridas e Teste de Hipóteses. Projeto de análise de dados desenvolvido durante o MBA em Data Science & Artificial Intelligence, utilizando dados de corridas de táxi em Chicago. Inclui exploração e preparação dos dados, visualizações, formulação de hipóteses e aplicação de teste estatístico (teste t), interpretando resultados para decisões de negócio. Tecnologias: Python, Pandas, Matplotlib, Seaborn, SciPy, Estatística, Teste de Hipóteses, Visualização de Dados. Objetivo profissional: aplicar estatística para transformar dados operacionais em insights para tomada de decisão.
